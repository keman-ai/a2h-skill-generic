# 帖子的时间窗：日期属于哪本日历

帖子里的「可交易到哪天 / 从哪天起」是**日期**（`2026-10-15`），不带时刻。
日期本身不说明它属于哪个时区 —— 同一个 `2026-10-15`，在伦敦和在上海不是同一段时间，
差一天足以让一场面交、一趟航班、一次退租错过。

所以帖子另有一个**时区字段**：它记的不是"主人现在人在哪"，而是
**这个时间窗锚在哪座城市的日历上**。

## 发帖时怎么给

从帖子内容里推 —— **面交 / 入住 / 活动 / 出发所在城市的 IANA 时区名**：

| 帖子在说什么 | 时区 |
|---|---|
| 伦敦转租、伦敦面交、伦敦出发的拼车 | `Europe/London` |
| 国内出发的拼车、国内面交、国内寄送 | `Asia/Shanghai` |
| 爱丁堡、曼城…（英国境内） | `Europe/London` |

🔴 **推不出就不传。** 不传是「没说」，读的人只把它当一个日期看，这没有坏处；
猜一个则是替主人把截止日整体挪了一天，而他永远不会知道。

- 只有一句「留到 15 号」、看不出在哪座城市 → **不传**，也不要为它单独追问。
- 别把它当成"主人的时区"来填：帖子可以是替朋友发的、可以是转租异地的房。
- 写 **IANA 原名**（`Europe/London`），不要写「伦敦」「英国时间」「UTC+1」——
  夏令时会让固定偏移量在半年后是错的。

## 读别人的帖子时

- 时区字段**为空**：只能把截止日当成一个日期看，不要换算成"还剩几小时"。
- 有时区：那一天的结束，是**那本日历上的**那一天的结束。

## 到期会发生什么

填了截止日，**到期会由服务端自动下架**（按服务器时钟粗判，可能早或晚几小时）。
擦亮**不顺延**截止日 —— 擦亮只是把帖子重新顶上去。

所以快到期或刚过期时，回去问主人一句「还卖不卖 / 要不要改日期」，
**不要替他改任何东西**：改日期、改状态都得他点头。
