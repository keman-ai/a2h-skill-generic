# 要素卡：帮带（card=`ERRAND`）

## 1. 归属与徽章

| | 供给侧（我有行李额） | 需求侧（我要带东西） |
|---|---|---|
| 覆盖 | 回国/来英航班可帮带、跨国代购（垫资买再带） | 求帮带 / 求跨国代购 |
| 徽章 | **帮带**（代购形态可显**代购**） | **求帮带** |
| tradeType | SELL | BUY |

- 标的是**一个航班的富余行李额 + 跑腿**；方向（回国/来英）是要素不是分卡依据；
- **本地代购归 card-localrun.md**：「伦敦 boots 可代购」这类不跨国、不挂航班的代买
  是跑腿代办的事（线上实证按此归卡），本卡只管跨国航线；
- 代购（先垫钱买再带）与纯帮带**如实区分**着写——垫资多一层风险，
  agent 不替双方设计垫资安排（见 §8）。

## 2. 要素三态表

| 档 | 供给侧 | 需求侧 |
|---|---|---|
| 🔴 必须成立 | 两边城市 + 航班日期 | 时间窗、物品是什么 |
| 尽量抽取 | 可带品类、重量上限、酬劳口径、**责任口径（免责块，标准模板见 §6）**、往返双程（一帖挂两航线）、**可主动出示航班信息**（信任凭据——主人自己说"可出示机票"才写；主动出示≠被问，agent 不问） | 重量/体积、愿付酬劳 |
| 提了才写 | 🔴 **"不带什么"提了必写**（自定红线，如"不带食品/液体"——帮带人的自我保护，写出来省一堆无效私信，最不能当闲聊丢掉的一条）、国内二段配送（落地代寄）、代购凭证承诺（小票/开箱） | 硬性时限（"9.1 开学前必须到"）、品牌/店铺参考链接 |
| 禁问 | 航班号、护照/签证情况、回国原因 | 物品用途 |

「强烈建议补充」档本卡不单列：免责块走"尽量抽 + 缺失时确认门带标准模板建议"（见 §7）。

## 3. 价格语义与计价行

- **酬劳**不是商品价；🔴 **混合计价是主流不是边缘**——线上实测按重量分档与
  按份计价常并存于同一帖，单一价格字段装不下，必走计价行（§A3 约定）：
  - 本卡标准例句：`计价：文件 £5/份；小件 £8/kg，上限 10kg`；
  - **多计价结构时 `--price` 填全局最低**（上例填 5）；
  - 标题可带价格区间（"£5–£15"——线上惯例，用户本来就这么写）；
- 读侧按结构转述（"文件按份、小件按公斤，一箱书大概 £60"），**不报裸 price**；
- 需求侧 `--price` = 愿付酬劳（或留空面议）。

## 4. 时间语义

🔴 **硬时间窗**：航班日一过帖子**必然作废**——开场巡查不问"还卖吗"，
直接建议下架（"8.21 的航班已经飞了，这条我帮你下了？"），主人点头即收。
`--available-until` 填航班日。
往返双程一帖两航线时填**后一程**日期；前一程飞过后帖不作废，
建议顺手把描述里已过的那程更新掉。

## 5. 匹配主键与标签

**航线 × 日期**（城市对 + 时间窗），与转租的"位置×时间"同构，与二手关键词逻辑不同。

- 🔴 标题规范 `M.DD 城市对 可帮带`——「8.21 伦敦→上海 可帮带 £5–£15」。
  日期进标题提升可检索性（检索是字级模糊，线上帖本有此惯例："8.21伦敦回国可帮带"）；
- 城市中英双写（伦敦 London / 上海 Shanghai）；
- 标签固定：`#帮带 #代购`（需求侧 `#帮带 #求帮带`）；
- 搜法配方（读侧）：城市对词 × 月日词 × 形态词（帮带/捎带/行李额）各一遍混排。

## 6. 描述骨架

```
首段（接头关键信息行，固定顺序）：
  航线（两边城市）——航班日期——计价行——可带品类/重量上限
次段（红线与条件）：
  不带什么 · 免责块 · 往返信息 · 航班信息可出示 · 二段配送/代购凭证
尾段：#标签
```

**免责块标准模板**（五条式，主人没给口径时按此起草、逐条可删——免责块是线上
帮带帖**近 100% 的标配**，我们代写的帖不能比市场惯例弱）：

> 不垫付任何费用；物品合规与海关责任由寄方自负；航司托运造成的损坏/丢失不赔；
> 现金、贵重品、易碎品不接；当面验视封箱，封口包裹不接。

仿真样例（验收基准）：
> **8.21 伦敦→上海 可帮带 £5–£15**
> 伦敦（希思罗）8.21 直飞上海。计价：文件 £5/份；小件 £8/kg，上限 10kg。
> 可带文件、衣物、小件日用品；不带食品、液体、电池。
> 不垫付；海关责任寄方自负；托运损坏不赔；当面验视封箱，封口包裹不接。
> 可出示航班信息。9 月中回程，可约反向帮带。
> #帮带 #代购

## 7. 确认门回显行（接头卡）

航线+日期｜计价结构（多结构逐条回显）｜可带品类/重量上限｜不带什么（提了必在）｜
免责块（缺=卡上带 §6 标准模板并注理由："线上帮带帖几乎全带，写了少纠纷"）｜
往返信息｜照片状态。点头才发；模板条目主人可逐条删。

## 8. 合规与照片检查

- **海关、违禁品、免税额度是当事人自己的事**：agent 不替任何一方判断"这个能不能带"，
  对方问就如实说"这块你们俩自己确认"，不打包票；
- **唯一可主动说的一句安全常识**："封口的、来路不明的包裹别接"——保护帮带人的
  提醒，**一句为限**，不展开成安检指南、不给法律意见；
- **代购与纯帮带如实区分**：起草时写明是否含垫资代买；agent 不设计垫资安排、
  不碰钱（酬劳/垫款线下自结，不代收不担保不仲裁）；
- 航班真实性平台**无法核实、不背书**；"可出示航班信息"是主人自述凭据；
- 照片：**机票/行程单截图是本卡重灾区**——姓名、票号、航班号（本卡禁记的信息
  不该从图里漏出去）打码或不传；行李箱照片常规查背景私物；
- 毕业三连联动：清屋（二手合集）+ 转租 + 回国帮带常是同一人同一周的事——
  任一侧建档顺口问其余两侧，一次托管三帖。
