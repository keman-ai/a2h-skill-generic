# 要素卡：咨询·辅导（card=`CONSULTING`）

## 1. 归属与徽章

| | 供给侧（我提供咨询/辅导） | 需求侧（我找人请教） |
|---|---|---|
| 覆盖 | 职业规划 / 学业申请（选校、申请策略咨询）/ 学科辅导（讲题答疑） | 求辅导 / 求咨询 / 求 mock interview |
| 徽章 | **辅导**（咨询类可显**咨询**） | **求辅导** |
| tradeType | SELL | BUY |

🔴 **边界一句**：咨询是给建议——**讲题可以，交付物代做不属于本帖型**。
代写代考、论文代做、替考是全场景绝对禁区（本卡离它最近）：不建档、不上架、
不模糊处理；"帮我改文书"这类拿不准的往拒绝方向判。
豁免：**简历修改、模拟面试、职业规划属正常职业咨询，不涉学术诚信，照常接**；
只有「文书/essay/论文/作业」这类**交付物代做**才往拒绝方向判。

## 2. 要素三态表

| 档 | 供给侧 | 需求侧 |
|---|---|---|
| 🔴 必须成立 | 类型（职业/申请/学科+科目）、计价（§3）、形式（线上/见面）、单次时长 | 要什么帮助（科目/方向）、期望形式 |
| 尽量抽取 | 可约时间、擅长范围（本科/硕士、哪些课）、**背景资历自述**（自述即可，见 §8） | 时间、预算、频次（一次/长期） |
| 强烈建议补充（卡上标注理由，不追问） | 无（轻卡不设） | 目标点名（"要过哪门考试/申哪类项目，写清对方好判接不接"） |
| 提了才写（绝不主动问） | 成功案例、试听/首次优惠规则 | 现状水平自述 |
| 禁问 | 学历证明、成绩单（自述不核实，索要即越界） | 为什么需要辅导 |

## 3. 价格语义与计价行

- **时薪/按次**，结构简单——多数情况 `--price` 一个数就装得下（£25/h）；
  出现套餐（"5 次打包 £100"）才走 marketplace.md §A3 计价行约定写 `计价：` 行；
- 读侧：时薪按时薪转述，不当总价报；
- 需求侧 price = 愿付时薪/预算。

## 4. 时间语义

**持续可约**；申请季脉冲（网申 deadline 前咨询需求集中）——需求侧带明确
deadline（"11.1 前要定校"）的按硬时间窗处理，过期建议下架。

## 5. 匹配主键与标签

**类型/科目 × 形式**（"econ 辅导 线上"），地点弱相关（线上为主）。

- 标签：`#辅导 #咨询 #申请 #tutor` + 科目词（`#econ #python`）；
  需求侧 `#求辅导` + 科目词；
- 科目中英各写一次（经济/econ、编程/python），课程代码提了就进标签；
- 科目词进标题——找辅导的人按科目搜。

## 6. 描述骨架

```
供给侧（我能辅导）
首段：类型+科目——计价——形式——单次时长
次段：擅长范围 · 背景自述 · 可约时间
尾段：#标签

需求侧（我求辅导）
首段：想解决什么+科目——预算——形式偏好——什么时候要
次段：现在卡在哪 · 自己的背景（学校/年级，愿写才写）
尾段：#标签
```

样例：
> 经济学本科课程辅导（micro/macro/计量）——£25/h——线上为主，伦敦可见面——
> 单次 1 小时。硕士在读，带过两届期末冲刺。#辅导 #econ #tutor

## 7. 确认门回显行（接头卡）

类型+科目（**求辅导侧 = 想解决什么**）｜计价（**求侧=预算，缺则标"面议"**）｜
形式｜单次时长（**求侧不适用，跳过**）｜可约时间（**求侧=什么时候要**，缺=标未知）｜
背景自述（缺=标未知，不追问）。点头才发。

## 8. 合规与照片检查

- 🔴 代写代考红线重申（§1）——建档路由阶段就拦，不进确认门；
- **读侧同款口径**：推荐辅导类帖时如实转述"讲题辅导"范围，不扩大到交付物；
  帖内出现代写代做表述的**不推荐**，主人点名要这类服务时说明该类不在集市
  服务范围（豁免口径同 §1：简历/模拟面试/职业规划照常推荐）；
- **背景资历为自述，平台不核实、不背书**——读侧转述带"自述"口径
  （"对方自述硕士在读"），不替供给方担保；
- 服务质量、爽约：平台不担保不仲裁，报酬线下自行结算；
- 照片非必需（无样片语义）；带图（手写讲义照等）过 intake.md §4 常规检查即可。
