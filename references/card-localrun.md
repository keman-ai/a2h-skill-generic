# 要素卡：跑腿代办（card=`LOCALRUN`）

## 1. 归属与徽章

| | 供给侧（我可接单） | 需求侧（我找人办） |
|---|---|---|
| 覆盖 | 可代取快递 / 可代排队 / 本地可代购 / 其他单次代办 | 求代取 / 求代排 / 求代购 / 求代办 |
| 徽章 | **跑腿** | **求代办** |
| tradeType | SELL | BUY |

- 线上以**求帖为主**——本卡需求侧是常态方向，供给侧（挂出"可接单"）少见；
- 边界①：**本地代购归本卡**——不跨国、不挂航班的代买（"boots 可代购"线上实证
  归此）；跨国带货/垫资代购归 card-errand.md；
- 边界②：**单次微服务**——同一雇主持续受雇（每周固定帮工/长期兼职）是 card-job.md
  的事，建档听到"长期/每周固定"就换卡。

## 2. 要素三态表

四要素：**事项 + 区域 + 时段 + 报酬**。

| 档 | 供给侧 | 需求侧 |
|---|---|---|
| 🔴 必须成立 | 事项范围（接什么单）、区域、可接时段 | 事项（办什么）、区域、时段 |
| 尽量抽取 | 报酬口径（说不清落"面议"，但要素行必须在）、工具条件（有车/有推车） | 愿付报酬（同左，面议照发）、物品大小/件数、垫资金额（涉代购必抽） |
| 提了才写 | 不接什么（如不代购烟酒/不搬重物） | 加急时限、交接方式偏好 |
| 禁问 | 接单原因 | 为什么自己不去办 |

## 3. 价格语义与计价行

- **报酬** = 单次事项价，一口价直接 `--price`；
- 费率结构走计价行（§A3 约定）：「计价：排队 £10/小时；代取快递 £3/件，Zone1 内」，
  `--price` 填起步/最低价；读侧按结构转述不报裸数；
- 需求侧 `--price` = 愿付报酬（或留空面议）；
- **垫资自协商**：本地代购常要先垫货款——金额如实写进描述（"需垫付约 £30 货款"），
  结算方式双方自行商定，**平台不碰钱**。

## 4. 时间语义

- 常态是**时段可约**（"周三下午均可"）——软时限，过期开场巡查照常问收尾；
- 例外：事项自带场次/截止（代排某日发售队、代取有滞留期限的快递）——
  该时点一过按硬时间窗口径直接建议下架；
- `--available-until` 填事项截止日；持续可约类留空。

## 5. 匹配主键与标签

**区域 × 事项**（"UCL 附近代取""伦敦 boots 代购"）。

- 事项词中英+长短变体各写一次：代取/代拿/pickup、排队/代排、代购/代买；
- 区域词同 card-rental.md 口径：区名/地铁站/学校名，多词连写；
- 标签：`#跑腿 #代办` + 事项词（`#代取 #代排 #代购`）；需求侧加 `#求代办`；
- 搜法配方（读侧）：区域词 × 事项词各变体混排。

## 6. 描述骨架

```
首段（接头关键信息行，固定顺序）：
  事项——区域——时段——报酬（或计价行）
次段（细节与边界）：
  物品大小/件数 · 垫资金额 · 不接什么 · 交接方式
尾段：#标签
```

仿真样例（求帖为常态，样例给需求侧）：
> **UCL 附近求代取快递 周三下午**
> 代取快递 1 件（小件）——UCL 主校区旁驿站——周三 14:00–18:00 任一时间——酬 £5。
> 无需垫付；取件码接头后私信发。
> #跑腿 #代办 #代取

## 7. 确认门回显行（接头卡）

事项｜区域｜时段｜报酬/计价（缺=面议）｜垫资金额（涉代购必回显）｜交接方式｜
照片状态。凭据类信息（取件码/门禁码/到户门牌）出现在口述里 → 提醒主人
**不落帖面**，接头后私信给——这不是丢信息，回显时说明去处。

## 8. 合规与照片检查

- **平台只做单次信息撮合**：不核实接单人身份，不说"靠谱""放心"类担保词；
  持续雇佣不在本卡（转 card-job.md，雇佣相关口径在那张卡）；
- **垫资自协商**：代购垫款、报销凭证双方线下自理，平台不代收不担保不仲裁；
- **凭据红线**：取件码、门禁密码、精确到户的地址**不进帖面**——帖面写到
  街区/驿站级即可，剩下的接头后私下交接；
- 照片：**快递面单是本卡重灾区**（姓名/电话/单号/地址）——入镜必打码或不传；
  代购需求的商品截图查个人账号信息入镜。
