# 要素卡：物品租借（card=`LEND`）

## 1. 归属与徽章

| | 供给侧（我出借） | 需求侧（我求借） |
|---|---|---|
| 覆盖 | 学士服·毕业袍 / 相机·器材 / 行李箱 / 工具 | 求租借（毕业季蹲学士服是主流） |
| 徽章 | **出借** | **求租借** |
| tradeType | SELL | BUY |

## 2. 要素三态表

**与卖断的结构差异**：东西不换主。比 card-goods.md 多出**押金 / 租期 / 归还条件三件套**，
三者写不清帖等于没成立——没押金出借人裸奔、没租期各想各的、没归还条件扯皮预定。
三件套进必须成立档，**合并成一问**（"押金收多少、借几天、怎么还？"）不逐项轰炸；
问过没答仍标「未知」照发（软闸不拦发），但确认门上这三格的缺口主人必须亲眼过目。

| 档 | 供给侧 | 需求侧 |
|---|---|---|
| 🔴 必须成立 | 品名、计价（按天/次/周 + 币种）、**押金**、**租期**（可借时长/档期）、**归还条件**（面交还/邮寄回/清洁要求） | 要借什么、要用的时段 |
| 尽量抽取 | 物品状况（成色/功能正常）、可借档期起止 | 预算、地点 |
| 提了才写 | 超期规则、损耗界定、"仅限本校" | 用途（"毕业典礼用"帮出借人放心，但不问）、可接受替代（"同色系袍子都行"=软偏好不追问） |
| 禁问 | 借去干什么（对方没提不问） | 押金承受力不评价 |

## 3. 价格语义与计价行

**周期价** → 描述首段固定计价行（计价行约定见 marketplace.md §A3）：

> 计价：£10/天（3 天起借 £25），押金 £50 归还完好后退

- `--price` 填起步价或留空面议；
- 读侧按结构转述**不报裸数**——"£10 一天、押 £50"，不是"£10"；
- 🔴 押金纪律：如实转述主人的押金规则，**不代收、不托管、不替双方设计押金方案**；
- 需求侧 `--price` = 预算（写清是租金预算；押金承受度提了才写）；
- 可租可买的混合需求帖（"求借或收一个行李箱"）：`--price` 填**买断预算**
  或留空面议，描述写清双口径（租金预算/买断预算各多少），不把两个口径混进一个数。

## 4. 时间语义

**持续可约 + 档期窗**双态。学士服是**日期驱动**的：毕业典礼日就是需求日，
档期错了白谈——档期起止尽量抽，主人说了典礼日必落。
供给帖 `--available-until` = 出借窗口截止；
需求帖"7.18 典礼要用"**日期一过 = 帖作废**，按硬时间窗直接建议下架。

## 5. 匹配主键与标签

**品名 × 档期**。

- 学士服写全变体：学士服/毕业袍/graduation gown + **学校名**（各校袍色制式不同，
  校名是硬匹配键）；相机带型号；行李箱带尺寸（28寸/大号）；多词连写；
- 时间词进标题（"毕业季可借""7 月档期"）；
- 标签：`#租借 #学士服 #毕业季 #相机`（需求侧 `#求租借`）。
- 🔴 **反查时同时搜 GOODS 的卖断帖**：可租可买的需求**两边都算命中**——求借人
  想要的东西常有人在直接卖（线上"出正版 UCL 硕士学士服"就归 GOODS 且归得没错），
  只按 `--card LEND` 筛等于把一半供给挡在外面；反过来给卖断帖找买家时也该看看
  LEND 侧的求借帖。本卡全站只有个位数存量，**一律先 keyword 后卡筛**。

## 6. 描述骨架

```
首段：品名（+学校/型号/尺寸）——计价行——押金——租期档期
次段：归还条件 · 付款/押金收付时点（租金先付还是后结、押金怎么收怎么退——提了必写）
　　· 物品状况 · 超期/损耗规则（提了才写）
尾段：#标签
需求侧：要借什么+时段——预算——地点——#标签
```

## 7. 确认门回显行

品名｜计价行｜押金｜租期档期｜归还条件｜物品状况｜照片状态——
**三件套缺哪格都点名标出**给主人过目再发（缺押金标注"没写押金，
出借的风险你自己担，确认就这样发？"）。
需求侧回显：要借什么｜时段｜租金预算｜地点；发布后照 card-goods.md §7
固定反查在售/在借。

## 8. 合规与照片检查

- **损坏责任双方线下自定，平台不仲裁**：损耗界定、赔偿口径是双方私下约定，
  agent 转述条件不当裁判、不给赔偿建议；
- 不碰钱：押金/租金线下自行结算（同 card-rental.md"不碰钱"口径）；
- 照片常规敏感检查（公共工序）；器材/袍子实拍常在家里拍——居家环境、
  他人私物入镜同 card-rental.md 红线单独问一句。
