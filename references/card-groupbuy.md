# 要素卡：拼团（card=`GROUPBUY`）

> 覆盖团购外卖 / 超市拼单 / 会员卡拼 / 集运拼箱。
> 成立前提是边界收紧为「**平台只做组局信息，货款参与者线下自行结算**」——
> 读本卡任何一栏都以这条红线为前提。公共工序不进卡，见 intake/marketplace。

## 1. 归属与徽章

| | 供给侧（我发起拼） | 需求侧（我想找拼） |
|---|---|---|
| 覆盖 | 团购外卖凑单 / 超市（Costco 等）拼单 / 会员卡合拼 / 集运拼箱 | 求带一份 / 蹲某类拼局 |
| 徽章 | **拼团** | **求拼** |
| tradeType | SELL | BUY |

绝大多数是发起帖（供给）；"谁有 Costco 卡带我进"这类求带 = 需求侧。

## 2. 要素三态表

| 档 | 供给侧（发起） | 需求侧（找拼） |
|---|---|---|
| 🔴 必须成立 | **拼什么、人均、成团人数、截止时间**——四项缺一即问（合并问） | 想拼什么、大致预算 |
| 尽量抽取 | 交收方式（**自提点在哪 / 谁负责分发**）、总价与拆分口径、平台/店家名、已凑几人；集运支线：路线（如英→中）、箱型/限重、货物限制 | 地点范围、时间灵活度 |
| 强烈建议补充（标注理由，不追问） | 结算方式先说清（"人均怎么收、什么时候收，写了省得成团后扯皮"）、会员卡拼写清使用规则（"一张卡几人用/怎么轮，写清避免误会"） | 能接受的自提距离 |
| 提了才写（绝不主动问） | **成团失败怎么处理**（不凑单退不退/顺延不顺延——主人提了才写，agent 不主动设计规则）、对拼友的要求 | 自我情况 |
| 禁问 | 进货渠道/会员卡来源合规性不盘问（但见 §8 红线） | 预算合理性不评价 |

## 3. 价格语义与计价行

**分摊价**，不是"一个数"——走计价行约定：

- 描述首段固定 `计价：` 行，标准例句：**「计价：人均 £12，拼满 4 人；截止周五」**；
- `--price` 填人均数（人均不定时留空面议）；
- 人均与总价换算当场核对（"总共 £48 四个人"→ 确认人均 £12）；
- 读侧：见「人均/每人/AA/成团」结构按分摊价转述，**不裸报 price 字段**
  ——裸报会把"人均 £12"读成"整单 £12"。

分界一句：**合买分摊 → 本卡；出行分摊 → 拼车·接送机卡（card-carpool.md）；
只是约着一起做事、各付各的 → 找搭子卡（card-companion.md）**。

## 4. 时间语义

**截止点**：拼团为某个截止时间攒人（下单截止/发货截止/拼柜截止），
`--available-until` 填截止时间。**截止已过 = 帖必作废**，读侧直接建议下架。
集运拼箱按船期/拼柜日同理，截止点到小时的照实写。

## 5. 匹配主键与标签

**拼的东西/平台 × 地点（自提点）**（"Costco 拼单 · 学校附近自提"）。

- 标签固定：`#拼团 #拼单`；按支线加 `#外卖 #Costco #会员卡 #集运 #拼箱`；
- 平台/店家名是第一搜索词，中英+俗称各写一次（Costco/开市客）；
- 地点词（自提点所在区/校区）进标题或标签，多词连写；
- 搜法配方（读侧）：平台词 × 地区词 × "拼/凑/带一份" 混排。

## 6. 描述骨架

```
首段（组局关键信息行，固定顺序）：
  计价：人均 £X，拼满 N 人；截止<时间>——拼什么（平台/店家/品项）
次段（交收与规则）：
  自提点与分发方式 · 结算方式 · 已凑人数 · 成团失败处理（提了才写）
  （集运支线：路线 · 箱型限重 · 货物限制）
尾段：#标签
```

样例：
> 计价：人均 £12，拼满 4 人；截止周五 20:00——Costco 拼单，周六去采购，
> 帮带常规食品日用。周六晚学校正门自提，费用按小票当面结。目前已 2 人。
> #拼单 #Costco #拼团

## 7. 确认门回显行（接头卡）

拼什么｜人均｜成团人数｜截止时间（四项缺任一 = 建档时已问）｜
自提点/分发（缺=标未知）｜结算方式（缺=标注建议句）｜已凑人数。
点头才发；「强烈建议补充」项带理由摆卡上，主人自己决定。

## 8. 合规与照片检查

- 🔴 **平台只做组局信息，货款参与者线下自行结算**——agent 不代收款、不担保
  发起人会交货、不裁决"没成团钱怎么退"；确认门与读侧转述都不出现任何
  "平台保障"字样。这是本卡从「不做」翻案成「做」的唯一前提，越线即回到 0803 结论；
- 成团失败/退款纠纷：**接头前提醒双方自行约定**可以，介入处理不行；
- 私房菜/自制食品代售不属于本卡（食品经营监管，帖型体系明确排除）；
  代购转卖性质的"拼"若有清关/限购红线，照实转述发起人说法、不背书；
- 照片：小票/订单截图**遮个人信息**（姓名/地址/卡号）；会员卡照片不上帖。
