# 要素卡：找搭子（card=`COMPANION`）

> 覆盖活动搭子（吃饭/看展/演出同行/运动局）与**语伴支线**（语言交换）。
> 组局骨架五要素：**做什么 × 时间 × 地点 × 人数 × 费用方式（AA/免费）**——
> 本卡一切要素引导围绕这五项展开。公共工序（口述落位、确认门流程、追问上限、
> 币种规则）见 intake/marketplace 全局定义，不在本卡重复。

## 1. 归属与徽章

| | 供给侧（我发起局） | 需求侧（我想加入） |
|---|---|---|
| 覆盖 | 饭搭子 / 看展观演同行 / 运动局 / 语伴（发起方） | 想找个局加入 / 求语伴 |
| 徽章 | **找搭子**（语伴支线可显**找语伴**） | **找搭子** |
| tradeType | SELL | BUY |

本卡供需界限天然模糊：**发起局 = 供给，想加入 = 需求**，但实践中绝大多数是
发起帖——"周六看展求同行"既是发起也是想加入。判侧存疑时按发起帖（供给）建档，
两侧要素几乎镜像，判错代价低。

## 2. 要素三态表

| 档 | 供给侧（发起） | 需求侧（想加入） |
|---|---|---|
| 🔴 必须成立 | 做什么（活动内容）、时间 | 想做什么、大致时间段 |
| 尽量抽取 | 地点、人数（已有几人/还差几人）、费用方式（AA/免费）；**语伴支线**：语言对（如中英互换）、各自水平、线上/线下、频次 | 地点范围、自己的情况（水平/经验，运动局和语伴尤其） |
| 强烈建议补充（标注理由，不追问） | 活动细节链接或票档（"写清是哪场，来的人不用再问"）、集合方式（"约在哪碰头先说好"） | 时间灵活度（"写清哪几天有空，发起人好排"） |
| 提了才写（绝不主动问） | 对搭子的偏好（性别/年龄段/水平门槛）、自我介绍 | 自我画像 |
| 禁问 | 为什么一个人来 / 交友意图——本卡不是相亲交友（该类不纳入，见帖型决策） | 同左 |

## 3. 价格语义与计价行

**无价格语义是常态**——搭子局不是买卖：

- `--price` **多为空**，留空不追问、不标"面议"；
- 费用方式（AA / 免费 / 各付各的）是**描述里的一句话**，不进 price 字段：
  「门票各买各的，饭钱 AA」；
- **语伴支线通常免费互助**（语言交换的对价就是语言本身），价格位整体不出现；
- 读侧：本卡帖子不报价格，转述费用方式原句即可。

分界一句：**同样是"分摊"，出行分摊 → 拼车·接送机卡（card-carpool.md），
合买分摊 → 拼团卡（card-groupbuy.md）**；本卡的 AA 只是"各付各的活动"，不涉及代收代付。

## 4. 时间语义

**活动时间窗**：局是为某个时间点/时段攒的，`--available-until` 填活动开始时间
（或报名截止）。**活动时间已过 = 帖必作废**，读侧遇到直接建议下架，不问"还去吗"。

例外：**语伴支线是持续可约**（每周一次咖啡馆练口语），无截止点，
`--available-until` 留空，过期逻辑不适用。

## 5. 匹配主键与标签

**活动类型 × 时间 × 地点**（"周六 · 羽毛球 · 东伦敦"）。

- 标签固定：`#搭子 #组局`；按支线加 `#饭搭子 #运动 #看展 #演出`，
  语伴加 `#语伴 #语言交换 #英语口语`；
- 活动词写全变体：中英各一次（羽毛球/badminton、看展/exhibition）；
- 时间词进标题（"周六""这周日下午"）——找局的人第一搜法是"活动词+时间词"；
- 搜法配方（读侧）：活动词 × 地区词 × "搭子/同行/一起" 混排。

## 6. 描述骨架

```
首段（组局骨架行，固定顺序）：
  做什么——时间——地点——人数（已有几人/还差几人）——费用方式（AA/免费）
次段（条件与补充）：
  活动细节/票档 · 集合方式 · 对搭子的偏好 · 发起人自述
  （语伴支线：语言对 · 各自水平 · 线上线下 · 频次）
尾段：#标签
```

样例：
> 这周六下午 Tate Modern 新展同行——14:00 门口集合——目前 2 人还可加 2 人——
> 门票各买各的，看完想喝咖啡的 AA。
> #搭子 #看展 #组局

## 7. 确认门回显行（接头卡）

做什么｜时间（语伴=频次）｜地点（线上/线下）｜人数（缺=标未知）｜
费用方式（缺=默认不写，不推断 AA）｜偏好（提了才有）。
点头才发；「强烈建议补充」项带理由摆卡上，主人自己决定。

## 8. 合规与照片检查

- **线下见面安全自负**：平台不核实任何一方身份、不做背书——建档时不承诺
  "都是学生/都靠谱"，读侧转述也不替发起人打包票；首次见面选公共场所是
  **可提醒不可承诺**的常识句；
- **不碰钱**：AA 结算两边当面处理，agent 不代收、不建议任何代付安排；
- 照片：活动海报/场地图安全；**含他人人像的合影要单独问一句**（肖像权），
  聊天记录截图（约局群聊）常查可读信息。
