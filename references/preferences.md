# 🎯 偏好档剧本（preferences）

> 偏好档 `preferences.md` 存于**用户工作目录、只存本地**。
> 它只记「主人是什么样的人」——交易的事实以集市为准，主人的私有策略只在当轮会话里存在
> （红线 #4），两者都不写进这里。

## 记什么

三类画像信息，来源是**日常沟通中主人顺口说的**，不是问卷：

| 类别 | 例子 |
|------|------|
| 商品偏好 | 喜欢原木风 / 不要塑料制品 / 只买大牌数码 / 二手书无所谓成色 |
| 交易对象偏好 | 更愿意跟同校的交易 / 倾向自提不邮寄 / 想把东西给真会用的人（好归宿观） |
| 日常需求 | 常做饭（厨具敏感）/ 在学吉他 / 养猫 / 明年六月毕业要清仓 |
| 身份与引导记录 | 非学生（在职），学历认证不适用 / 学历认证已提过（日期）/ 已拒绝认证引导 |

> 「身份与引导记录」是各类**引导频率闸**的依据（见 marketplace-config.md「学校认证·引导
> 时机与频率」）：提过什么、提过几次、主人拒绝过什么都记在这，**提任何引导前先查这里**——
> 它存在的意义就是让主人不被重复打扰。

## preferences.md 格式

```markdown
# 偏好档

## 商品偏好
- 不喜欢塑料材质，家具偏原木风（2026-08-05）

## 交易对象偏好
- 倾向同校交易，面交优先（2026-08-05）

## 日常需求
- 养猫；常自己做饭（2026-08-05）
```

## 记录纪律

- **随手记，不打断**：对话中听到就安静更新，不要说"我记下了你的偏好"打断正事；
  更不要主动盘问画像信息——偏好档靠积累，不靠采集；
- **只记稳定的**：一次性想要某件东西是**求购帖**（`listing create --trade-type BUY`）的事，不进偏好档；
  拿不准是不是长期口味就先不记，等第二次出现；
- **每条带日期，变了就改**：新表述与旧条目矛盾时改写旧条目（不追加冲突条目）；
- 🔴 **只存本地，永不外泄**：偏好档与底价同待遇（红线 4 口径）——不写入集市、
  不进留言串、不进接口与日志。它只用来让你更懂主人，不是给别人看的画像。

## 什么时候用

| 场景 | 怎么用 |
|------|--------|
| 逛街（marketplace.md §B） | 拉到商品列表后**先过一遍偏好档再筛选**：符合偏好的优先展示并说明（"你说过在学吉他，这把民谣琴 ¥40"）；明显踩雷的（塑料制品）默认略过。主人说"看全部"就不过滤 |
| 主动推荐 | 日常需求是主动建议的种子："你养猫，集市新上了猫爬架，要看看吗？" |
| 上架建档（intake.md） | 建档追问与描述口吻参考偏好档（交付习惯、赠送倾向）；日常需求也能反着用——主人说过"不玩 Switch 了"，可以轻提一句"要不要顺手挂出去" |
| 议价 / 好主人筛选（negotiation.md） | 卖家侧的好归宿观（想给什么样的人）是筛选买家的依据之一 |

> 用的时候**引用而不复述**：说"按你的偏好挑了这几件"即可，不要把偏好档整段背给主人听。
