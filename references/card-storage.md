# 要素卡：行李寄存（card=`STORAGE`）

## 1. 归属与徽章

| | 供给侧（我有地方） | 需求侧（我要存） |
|---|---|---|
| 覆盖 | 假期寄存 / 毕业寄存（自住房/仓位） | 求寄存（回国过暑假/离境前中转） |
| 徽章 | **寄存** | **求寄存** |
| tradeType | SELL | BUY |

## 2. 要素三态表

| 档 | 供给侧 | 需求侧 |
|---|---|---|
| 🔴 必须成立 | 位置（区域/地铁站级即可，同 rental 口径）、**时段起止**、计价（按箱/月 + 币种） | 几箱几件、存多久（起止）、所在位置 |
| 尽量抽取 | **物品限制声明**（不收贵重/易腐/违禁）、可收容量（还能收几箱） | 预算、**到达日/取件日**（与 card-goods.md BUY 侧"到达日"同一维度：寄存时段的两头就是离境日和落地日） |
| 提了必写（不主动问，出现必落位） | 取放方式/预约（"提前一天约""可中超自提"——线上真实帖实证形态）、楼层/搬运条件 | 箱子尺寸/超重情况 |
| 提了才写 | 场地性质（自住/仓库）、是否可中途取放 | 贵重物说明 |
| 禁问 | 存的是什么逐件盘问（声明限制即可，不做开箱式追问） | 为什么要存 |

## 3. 价格语义与计价行

**计件 × 周期价** → 描述首段固定计价行（计价行约定见 marketplace.md §A3）：

> 计价：£8/箱/月，2 箱起 　或　 计价：£20/箱包整个暑假

- `--price` 填起步价或留空面议；口径（按月还是包段）必须写进计价行；
- 读侧按结构转述**不报裸数**——"£8 一箱一个月"，不是"£8"；
- 需求侧 `--price` = 预算，写清是单箱价还是总价。

## 4. 时间语义

**区间（起—止），两头都硬**：起 = 对方搬离/离境日，止 = 取件/到达日。
背景 = **毕业-新生错峰**：6–7 月存进去、9–10 月取出来是主流形态，
整个暑假是空窗——这也是"到达日"成为需求侧关键维度的原因。
供给帖 `--available-until` = 空间不再可用日；
需求帖"8.20 前要存进去"**窗口一过 = 帖作废**，按硬时间窗直接建议下架。

## 5. 匹配主键与标签

**位置 × 时段窗**（同 rental 逻辑——品牌型号式关键词匹配在本卡失效）。

- 区名/邮编/地铁站中英变体写全、多词连写（zone2 不留空格）；
- 月份词进标题（"暑假寄存""6 月起可存"）——找寄存的人第一搜法；
- 标签：`#寄存 #行李寄存 #暑假`（需求侧 `#求寄存`）。

## 6. 描述骨架

```
首段：位置——计价行——时段起止——可收几箱
次段：物品限制声明 · 取放方式/预约 · 楼层搬运条件
尾段：责任声明（见 §8）· #标签
需求侧：几箱+尺寸——存多久起止——位置——预算/到达日——#标签
```

## 7. 确认门回显行

位置｜计价行｜时段起止｜容量｜物品限制（缺 = 标「未知」）｜取放方式｜照片状态。
点头才发。需求侧：几箱｜时段｜位置｜预算，发布后照 card-goods.md §7 固定反查
在挂的寄存供给帖（错峰场景里供给帖常比求寄存帖早挂一个月）。

## 8. 合规与照片检查

- 🔴 **平台不担保不代管**：寄存是双方私下约定，**物品安全与损失责任自负**——
  建档时这句进描述尾行（"贵重物品请勿寄存，损失自负"类声明）；它不是免责套话，
  是给双方对齐预期的一行字，agent 不对保管质量做任何承诺；
- 不碰钱：寄存费/押金线下自行结算（同 card-rental.md 口径）；
- 照片检查重点：存放空间实拍常带家庭环境——室友/家人私物与人像入镜
  **单独问一句**（同 card-rental.md 红线）；门牌号可拍到楼不到户；
- 违禁品红线：主人声明"不收违禁"如实写；对方要存什么 agent 不核验、不背书。
