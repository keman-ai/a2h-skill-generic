# 🚪 开箱剧本（onboarding）

> 新用户接入 A2H Market 的完整流程。设计目标：用户侧 ≤5 分钟、只有一次浏览器授权感知。
> 全程自助：用户只需要一个 a2hmarket 账号和一台满足运行前提的机器，运营方零动作。

## 运行前提（三条）

不是"任何能跑 Python 的平台"就够，实际要三样：

1. **python3 ≥ 3.8**（macOS 自带）；
2. **能发 HTTPS 出网请求**——直连或系统出口任一条通即可；
3. **一个能安全写入的状态目录**——凭证要落在 0700 目录里的 0600 文件上。

第 3 条是最容易漏的：**家目录只读的托管沙箱**（ChatGPT 的 Web Work 一类）默认不满足，
要走下面第 ③ 步的 `auth login --session`。

**一条命令问清这三条**（只读：不生成授权码、不碰任何凭证、不改登录态）：

```bash
python3 scripts/a2hmarket.py doctor
```

它输出**单个 JSON**，顶层**恰好六个键**：`ok`（三段全就绪才为 `true`）、`python` / `network` /
`state` 三段各自 `ok`，外加 `loginSupported`（现在能不能走完一次登录）和 `optional`
（Pillow，可选能力，缺它不影响集市核心功能）。退出码 0=全部就绪、1=有项不 ok。

🔴 **遇到任何"装不上 / 连不上 / 登录不了"先跑它**，别靠猜、别逐条试。
🔴 **这份 JSON 是给你读的，不是给主人看的**：读完自己说人话，**别把整坨 JSON 甩到主人脸上**。
按**不 ok 的那一段**挑实质信息转述：

- `state` 不 ok → 说清 `state.error` 是哪种存不下，再把 `state.sessionFallback.howTo`
  那条命令给出去；走这条路之前先照 `state.sessionFallback.caveat` 说清代价；
- `network` 不 ok → 说 `network.attempted`——**本次实际试过哪几条出口**。
  照它排查，别去查一条根本没走过的通路；
- `state.scope` 已经是 `session` → 把 `state.sessionCaveat` 说给主人听：
  **这种登录不承诺跨聊天**，换个新聊天或换掉工作目录可能要重新授权一次。

字段与出网策略细则见 [marketplace-config.md](marketplace-config.md)。

## 先判定：这次要不要开箱

开场只看一个**本机可观测物**，**不凭聊天内容、也不凭"用户像不像老手"裁量**：

- **凭证**：状态目录下的 `credentials.json`。状态目录以 `a2hmarket.py config` 的
  `stateDirectory` 为准（默认 `~/.a2hmarket`；`A2HMARKET_HOME` 会改它；`--session` 登的在
  工作目录下的 `.a2hmarket-session`）——**别自己拼 `~/.a2hmarket`**，会话级登录时那儿是空的。

两种情况，对号入座：

- **凭证不在** → **全新安装**：**先做产品速览（授权之前！）**，用户点头后走
  授权 → 自检 → 报到建档；
- **凭证在** → **已开箱**：不重复产品速览，直接办用户的事。登录态失效（`auth status` 报未登录）
  只提示重新授权，**不等于**回到全新安装，不重跑本文流程。

🔴 **上次是会话级登录、这次读不到了**（新聊天 / 换了工作目录）：说
「**上次的会话已经结束，需要重新授权一次**」，然后重走一次 `auth login --session`。
**不要**说成"凭证失效了"或"集市出故障了"——那两句会把主人支去查完全不相干的东西。

> **取舍写在明处（有意为之）**：换机器、重装 skill 会让凭证缺席，于是重新开箱一次。
> 这是选出来的——宁可老用户多听一遍 30 秒速览，也不引入"已完成开箱"这类状态标记：
> 多一个状态文件，就多一处会漂、会脏、会跟事实对不上的东西；而重复一次速览
> 只值 30 秒，用户一句话就能打断（见下面「报到规则」的让位条款）。

## 开箱流程（agent 引导执行）

### ① 安装 skill

两种装法，**目录名都必须是 `a2hmarket`**（`SKILL.md` 里的 `name` 就是它；
装成别的名字，宿主认出来的技能名和 skill 自称的名字对不上）。

**git clone**（推荐，更新只要 `git pull`）：

```bash
git clone https://github.com/keman-ai/a2h-skill-generic.git ~/.claude/skills/a2hmarket
```

Codex 换成 `a2h-skill-codex` 仓 + `~/.codex/skills/a2hmarket`。

**或者**把下载解压得到的 `a2hmarket-skill/` 目录放进宿主的 skills 目录并改名为
`a2hmarket`：

- Claude 系：`~/.claude/skills/a2hmarket/`
- Codex：`~/.codex/skills/a2hmarket/`（由 Codex 自动发现 `SKILL.md`）
- WorkBuddy：`~/.workbuddy/skills/a2hmarket/`

🔴 **两种装法对应两种更新方式，别混**：git 装的一律 `git pull`；下载装的才走
「下载覆盖」那套（见下面「更新」一节的判据——看安装目录里有没有 `.git`）。

前置依赖见上面「运行前提」三条（`python3` + HTTPS 出网 + 可写状态目录）。
拿不准就先 `python3 scripts/a2hmarket.py doctor`。

### ② 产品速览（**授权之前**——装完第一时间说清我们是谁）

🔴 **顺序就是设计**：先介绍、后授权。用户在掏账号之前就该知道这是什么、能帮他干什么——
装完 skill 的第一次对话，第一时间说这段（口吻 = 熟悉行情的中介，短、说人话，
不是产品说明书）：

> **A2H Market 是留学生的二手集市**，我是你在集市里的中介——你只管说想卖什么、想要什么，
> 跑腿的事都归我：
> ① **卖东西**——一句话或一张照片，描述、定价、上架我全包，挂出去后让**离你近、
>    正好需要的人**更容易找到它；留个联系方式，买家看中了会直接来联系你；
>    **要清的东西往桌上一摊拍一张就行**——一张图里好几件，我帮你拆开，圈给你看
>    哪块是哪件、各自值多少，你点头我再发；
> ② **买东西**——说要什么、预算多少，我按价格和**离你远近**帮你挑最合适的；
>    刚搬来要置办一批？清单也可以丢给我，我一件件帮你找；
> ③ **逛一逛**——没想好买什么就说"看看有什么好东西"，我带你翻翻你周围最近在出的；
> ④ **发求购**——集市上一时没有的，挂个求购帖，有货的人会主动来找你；
> ⑤ **不止二手**——找室友、转租/短租招租、回国帮带代购这类"接头"的事也能挂：
>    「两室一厅找室友 £850/月」「7–8 月房间短租」「下周国内飞伦敦可帮带」。
>    发出来，要找的人自己来。
> 开始用需要先绑定你的 a2hmarket 账号——浏览器点一下「同意授权」，30 秒的事。现在开通吗？

> 🔴 介绍词的诚实边界：只说"更容易被找到"，**不说"我自动推荐给周围的人"**——
> 平台没有主动推送，夸出去就是下一个后台盯货幻觉。

速览规则：
- 用户第一句已带明确意图（"帮我卖沙发"）→ 介绍压缩成一句：
  "好，这单我来——A2H Market 是留学生二手集市，先花 30 秒绑个账号"，直接进授权；
- 介绍完用户在犹豫或提问 → 先答疑，不硬推授权；用户点头才进第 ③ 步。

### ③ 浏览器授权登录（唯一的强感知步骤）

发起时先把预期说清（授权页可能要几秒才打开，别让用户对着终端干等）：

> 我打开授权页了——用你的 a2hmarket 账号登录，点「同意授权」就行；
> 页面可能要几秒才打开，完成后回来说一声。

```bash
python3 scripts/a2hmarket.py auth login
```

会自动打开 **A2H Market 自己的授权页**（`a2hmarket.ai/authcode`）：
用户登录 a2hmarket 账号（同一套账号体系）→ 点「同意授权」→ 终端自动完成。
🔴 授权页刻意留在 A2H Market 域名下：用户是从 A2H Market 的 agent 发起授权的，中途跳去别的域名会让人以为点错了地方。
背后发生的事（用户无感）：CLI 生成一次性授权码，授权链接上**只带这一个码** → 授权页把
一枚 findu PAT（**`a2h_pat_*`**，180 天）绑到该码上，并**原地**渲染成授权成功
（页面不跳转、不回调任何地址）→ CLI 每 3 秒拿这个码走公开端点**单次兑换** PAT，
拿到即收口 → 存入状态目录的 `credentials.json`（0600，目录 0700）。

无头 / 远程开发机上打不开浏览器时走的是同一条路，不是降级方案：把终端里打印的那个 URL
拷到**任何一台**能上网的机器的浏览器里打开，点完「同意授权」终端就会收口。
授权页与 CLI 之间没有本机通道，所以两者在不在同一台机器上都不影响。

#### 家目录写不进去时：`auth login --session`（显式 opt-in）

```bash
python3 scripts/a2hmarket.py auth login --session
```

凭证改存进**当前工作目录**下的会话目录。**这必须由用户/你显式选**——CLI 不会自己
做这个决定：没有 opt-in 就把长效凭证挪进工作目录，等于替用户换了个他没同意的存放处
（工作目录还可能被整个打包上传出去）。`doctor` 在家目录存不下时会给一条
`state.sessionFallback`，照它说的走即可。

🔴 **`--session` 不承诺跨聊天**：凭证只在这次会话的这个工作目录里。
**换一个新聊天 / 新工作目录可能要重新授权**——`auth login` 成功回执里的 `stateHint`
就是这么写的，原样转述给主人，别加码成"下次就不用登了"。
同一次会话里换子目录调 CLI 不受影响（CLI 会逐级向上找）。

三种登录结果，说给主人听时口径不能串（字段是 `stateScope` / `persistent`）：

| 结果 | 意思 | 怎么跟主人说 |
|---|---|---|
| `persistent` | 凭证在家目录（或 `A2HMARKET_HOME` 指定的目录） | 老样子，一次授权长期有效 |
| `session` | 凭证只在这次会话的工作目录 | "这次先这么用；换个新聊天可能要再点一次授权" |
| 匿名（没有可写状态目录） | 登不了录，但 `market list` / `market show <listing_id>` 照样能逛 | "现在能带你逛集市，但发帖和私信要先能存下登录凭证" |

🔴 新聊天里读不到会话级凭证 → 说「**上次的会话已经结束，需要重新授权一次**」，
**不要**报成"凭证失效"或"集市故障"。

🔴 **ChatGPT 的 Web Work 是 best-effort 路径，不是 OpenAI 承诺的正式 standalone 安装面**——
能跑通就用，跑不通不算产品故障；**正式的 Web 分发仍然是 Plugin**。别向用户许诺它一直可用。

🔴 PAT 明文只在兑换那一刻出现在进程内存里：**不进 URL**（URL 全程只有一次性码）、不进日志、
不进任何本地文件、不发给任何人。

撤销授权（都立即生效、不可逆）：

```bash
a2hmarket.py auth logout              # 只清本机凭证，服务端那枚仍有效（换机器时用这个）
a2hmarket.py auth logout --revoke     # 连服务端一起撤销（本机不再用了 / 凭证可能泄露）
a2hmarket.py auth tokens              # 看名下所有 PAT，current=true 是本机这枚
a2hmarket.py auth revoke <id>         # 撤销指定的一枚（比如撤掉旧机器上的）
```

也可以到**主站**的「我的授权」页面删——同一份数据（findu-user 的 PAT 列表），两条入口等价。
**默认的 `auth logout` 不撤销服务端**：多台机器各有各的 PAT，在这台退出不该把别处的一起废掉。

### ④ 自检 + 建档（agent 执行，用户无感）

```bash
# 0. 环境自检（只读；三段全 ok 就往下走，哪段不 ok 就先照那段的字段处理，见上面「运行前提」）
python3 scripts/a2hmarket.py doctor
# 1. 链路自检：应返回 {"loggedIn": true}
#    （集市侧没有「我是谁」这个口——昵称/头像的唯一来源是主站，这里只验凭证可用）
python3 scripts/a2hmarket.py auth status
# 2. 能读集市吗？（应返回商品列表）
python3 scripts/a2hmarket.py market list --size 3
# 3. 看一眼档案（全部字段可选，纯了解现状，不构成任何门槛）
python3 scripts/a2hmarket.py profile get
```

**档案 = 对话内随时代填。唯一门槛：发帖需要至少 1 个联系方式**（帖子得联系得上）；
其余字段全部可选、不影响任何功能。
用户口述（"我微信 xxx、UCL 在读、住 Astor College"）就用 `profile set` 写入
（联系方式/标签是整组替换，改前先 `profile get` 拿全量；二维码图先 `photo upload`
拿 publicUrl 当值）。日常口径：**用户提了就用，不提不追**；
**绝不替用户编造档案内容**。唯一的主动集中采集是开箱报到那一轮（见下面「报到建档」），
之后只按档案触点兜底。网页 `/me` 页也能填，两个入口等价。

三项全过 → 进入**报到**（开通确认 + 建档）。

### ⑤ 报到：开通确认 + 建档

产品介绍在授权前（第 ② 步）已经讲过，这里**不复读**——一句确认收口，
紧接着**集中问一轮档案**。这是开箱唯一一次主动集中采集，
目的是让买家找得到你、也更信你。三样一起问、一次说清，不要拆成三连问：

> 搞定，A2H Market 开通了 🎉 想先卖点什么，还是逛逛集市？

> 对了，花 30 秒把档案立起来，之后买卖都省事：
> ① **联系方式**——邮箱或微信号至少一个（邮箱就够，买家联系得上就行），发帖必须有；
> ② **学校和身份**——比如"UCL 在读"，同校信任度最高；
> ③ **常驻地点和面交范围**——比如"住 Astor College，UCL 周边都能面交"，离得近才好成交。
> 直接说一句我就记下，也可以说"跳过"。

建档规则：
- **小红书主页也算联系方式**：主人说自己常发小红书、或发来自己的主页/帖子链接时，
  顺势提一句"小红书主页也能直接当联系方式挂上——买家去你主页私信你，微信邮箱都不用给"
  （`profile set --contact xiaohongshu=<主页链接或小红书号>`）；
- **先看第 ④ 步 `profile get` 的结果，只问缺的项**——已填过的不再问；
  三项全齐 → 建档整轮跳过，只发上面那句开通确认（老用户换目录重开箱时不被重复盘问）；
- 用户答了什么就 `profile set` 代填什么，**绝不编造**；只答了一部分，剩下的不追问第二遍；
- 用户说"跳过"或明显不想填 → **立即放行**，本会话不再集中问；之后只按档案触点兜底
  （见 SKILL.md「档案引导触点」，同一会话同类提醒最多一次）；
- 学校认证不在此时展开——刚绑定就要人认证太重；认证推荐固定在**上架商品时、
  首次开私密留言串时**顺带一句（见 SKILL.md 档案引导触点）；
- 这一轮**不构成任何门槛**：填多少都不影响功能，唯一硬门槛仍是发帖需联系方式 ≥1。

报到规则：
- 用户第一句已带明确意图（"我要卖 xx"）→ 速览已在第 ② 步压缩成一句，授权完成后
  开场只说"好了，这单我来"**直接干活**——速览永远让位于用户的事；报到建档也**不插队**，
  靠首次上架前的联系方式硬门槛和档案触点补齐；
- **同一会话里产品速览最多做一次**：开头讲过就不再复读，后面用户主动问"这是什么/怎么用"
  另算（那是他要听，按下条口径回答）；
- **不罗列全部能力**——议价代笔、手机寄件这些，等用到的场景自然出现；
- **不许诺还没上线的能力**（帖子上的联系方式展示、标签检索等仍在后端排队）。

用户后续任何时候问"这是什么 / 怎么用 / 你能干嘛"→ 用同一套速览口径回答，
按当时已上线的能力如实增减。

诚实边界（报到时如实说，不要许诺没有的能力）：
- 照片可以直接传——把图片存到电脑上告诉我路径，我上传后自动配到商品上（单张 ≤10MB）；
- 我不在线时的通知只有本机横幅——你离开电脑期间的急事，回来第一眼我会补给你。

## 身份说明

- 用户身份 = `user_<cognito sub>`（与 a2hmarket 同一账号体系），由 PAT 决定，无需也无法手填；
  **skill 本地不保存 userId** —— 集市接口的身份由网关从 PAT 反查后注入，本地存一份没有用处；
- 昵称 / 头像的唯一来源是主站（findu-user 的 `user_profile`），改名走主站的审核工作流，
  集市侧不提供改名入口；
- **集市侧档案**（联系方式 / 身份标签 / 常驻地点 / 偏好成交方式 / 偏好面交地点 / 可见性规则）用
  `profile get` / `profile set` 读写，**主路就是对话内代填**（全部字段可选）；
  可见性规则**只存储不生效**，别向用户许诺"同校才能看到你微信"已经在工作。

## 升级机制

skill 更新随正式分发渠道走。**版本检查是机械动作，不归你做**（0807 拍板）：
开场巡查（market-check.sh）每 **14 天**对云端 `latest.json` 比对一次，发现新版会在
开场情报里播一行 🆕（含该版的用户可读更新说明，**每个版本只播一次**）。你只做两件事：

- 看到 🆕 情报 → **转述更新内容、问主人要不要更新**。主人点头才执行下面的流程；
  不点头就过，不追问、不复读——下个版本出来巡查自然会再提一次。
  主人说「别再提醒更新」→ 把**状态目录**（`a2hmarket.py config` 的 `stateDirectory`）下
  `update-check.json` 里的 `muted` 置 `true`（读改写，别整文件覆盖），此后永不主动提；
  主人自己开口要更新不受此限。**状态目录不可用时这套频控整段不生效**——那就当没有新版，
  不要自己去查、也不要另找地方记；
- 🔴 **不要绕过频控自己查版本**：没有 🆕 情报就当没有新版。`market list` 报错、
  版本号看着旧，都不构成自行更新的理由。

**用户明确要求更新时**（不论有没有被提醒过），按下面的流程执行。

### 用户说「更新 a2hmarket skill」时

触发语示例："更新 a2hmarket skill" / "升级一下 A2H Market" / "重装 skill" / "换最新版"。
只有用户开口才做；`market list` 报错、版本号看着旧，都不构成自行更新的理由。

**先看一眼安装目录里有没有 `.git`**——有两条互斥的安装方式，用错更新方式会把用户的
安装弄坏：

- **有 `.git`**（用户是 `git clone` 装的）→ 更新就是在那个目录里 `git pull`，**到此为止**。
  千万别走下面的下载流程：删目录会连 `.git` 一起删掉，用户下次 `git pull` 就找不到仓了，
  而且他本地若有改动会一声不响地消失。
- **没有 `.git`**（下载安装的）→ 走下面的六步。

分发地址（固定，不要换别的来源）：

```
https://a2hmarket.ai/skill/a2hmarket-skill.zip
```

按顺序走完六步，**顺序不能换**——先备份后删除是这套流程唯一的安全网。
具体用什么命令、目录在哪，你当场判断，这里只规定每步要达成什么：

1. **定位安装目录**——就是当前这份 skill 所在的目录。不同宿主位置不一样（Claude 系在
   `~/.claude/skills/` 下，WorkBuddy 在 `~/.workbuddy/skills/` 下，还可能是项目内的路径）。
   **认不准就问用户，不要猜着删**。
2. **先备份**——把整个目录整份复制到临时位置。下载会失败、新包也可能有问题，
   没有退路就别动旧文件。
3. **下载并校验**——从上面那个地址取包，确认下全了、是完整 zip、解得开、
   解出来有 `SKILL.md` 和 `scripts/`。**任一条不过就原地中止**——此时旧文件一个没动，
   如实告诉用户失败原因即可。
4. **删旧装新**——删掉原目录再把新包**内容**放进去。注意 zip 顶层套了一层
   `a2hmarket-skill/`，要搬的是它**里面**的东西，别装成 `a2hmarket/a2hmarket-skill/` 的嵌套。
   直接解压覆盖而不删旧的做法不行：旧版本里被删掉的文件会残留下来。
5. **自检**——跑一次 `auth status`，确认新包能正常调通。
6. **失败就回滚**——自检不过，用第 2 步的备份还原回去，并如实告诉用户装失败了、已还原。
   **不要留一个半死不活的目录**。

装完向用户报一句新版本号（`SKILL.md` frontmatter 的 `metadata.version`）和自检结果，别默默结束。

🔴 **状态目录绝对不能删**（默认 `~/.a2hmarket`，`--session` 时是工作目录下的
`.a2hmarket-session`）——登录凭证 `credentials.json` 和运行缓存都在那儿，它在 skill 目录之外，
正常执行上面的流程不会碰到它。删了要重新走一遍浏览器授权。
里面的文件都是运行时状态，**不是要交付、预览、上传或分享的产物**，也不要展示内容。

🔴 **工作目录里的 `preferences.md` 也不要动**——偏好档记的是"主人是什么样的人"，
跟 skill 版本无关（[preferences.md](preferences.md)）。

**更新后第一次调用报 `auth_required` 且提示环境不符**：说明新包连的站点跟旧凭证不是
同一个环境（PAT 分环境签发，跨环境用不了）。如实告诉用户，让他重跑
`a2hmarket.py auth login` 重新授权——**不要**自作主张去找旧环境的包装回去。
